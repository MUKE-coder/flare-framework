## After it runs

The second block above is the whole setup: on Next.js it brings up Postgres,
creates the tables and seeds **admin@example.com** / **Password** to sign in
with; on Cloudflare there is nothing to provision at all. Then build
something:

```bash
npx flare gen resource Contact --fields 'name:string, email:email!, status:enum(lead,customer)'
npx flare migrate           # create its table
npx flare seed:resource Contact 1000
```

Walk the same path with more explanation in the tutorials —
[a contact app on Next.js](/tutorials/contact-next/) or
[on Cloudflare](/tutorials/contact-cloudflare/) — or skim the

storage driver are each one line to change in the app afterwards.
