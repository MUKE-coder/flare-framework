# __APP_NAME__

A [Flare](https://flare-docs.codetotech.com) app running on Cloudflare Workers via vinext.

```bash
__PM__ run dev             # start the dev server
npx flare dev --tunnel     # ...and share it on a public https://*.trycloudflare.com URL
__PM__ run build           # production build
__PM__ run deploy          # build and deploy to Cloudflare Workers
```

Docs: https://flare-docs.codetotech.com
